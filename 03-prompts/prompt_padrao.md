# Prompt Padronizado do Experimento

Você receberá uma unidade de código-fonte JavaScript pertencente a uma aplicação real.

Sua tarefa é gerar casos de teste automatizados para o código fornecido utilizando Jest.

## Instruções

1. Analise somente o código-fonte fornecido.
2. Gere testes automatizados compatíveis com Jest.
3. Não altere o código-fonte original.
4. Utilize mocks quando forem necessários para isolar dependências externas.
5. Teste o comportamento principal da função, método, middleware, controller ou serviço apresentado.
6. Inclua casos positivos e negativos quando forem aplicáveis.
7. Considere casos de borda relevantes.
8. Não forneça explicações, comentários externos ou instruções adicionais.
9. Retorne somente o código JavaScript correspondente ao arquivo de teste.
10. Não utilize bibliotecas de teste adicionais além das necessárias para Jest, salvo quando exigidas pelo próprio código.
11. Considere que o projeto utiliza Node.js e CommonJS.
12. O código produzido deverá poder ser salvo em um arquivo com extensão `.test.js`.
